# Implementation plan

## Phase A - preparation prototype

1. Foundation: npm workspace, role-separated routes, visual tokens, PWA shell, Express envelope, linked synthetic fixtures.
2. Administrator experience: coherent overview, threat search/filter/detail, campaign monitoring/detail, organisations, reports, alerts, and demo status updates.
3. Child experience: entry/role selection, safety check, screenshot preview, deterministic demo result, incident reporting, history, and pairing.
4. Parent experience: dashboard, child profiles, pairing code simulation, alerts, and notification preferences without conversation access.
5. Integration readiness: central analysis contract, Telegram/SMS/testbed ports, dataset registry, retrieval manifest, and honest feature flags.
6. Verification: lint, API tests, production build, responsive/browser review, manifest/service-worker checks, accessibility pass, and no-AI-slop visual audit.

## Phase B - hackathon build

1. Select licensed datasets and construct a synthetic Uganda-focused labelled evaluation set.
2. Establish baselines and report precision, recall, F1, false positives, and false negatives by scenario.
3. Connect approved pretrained classifiers and threat-intelligence feeds through adapters.
4. Add screenshot extraction and claimed-brand/domain evidence while avoiding automatic unsafe navigation.
5. Implement deduplication and measured similarity-based suspected campaign grouping.
6. Connect UCC Testbed inference and capture reproducible test evidence.
7. Connect one notification or messaging channel only after safeguarding and credential review.
8. Rehearse the five-scene demo and label every simulated versus live capability.

## Exit criteria

The production path requires real authentication, guardian verification, safeguarding review, approved reporting/referral partners, encrypted evidence storage, retention/deletion policy, incident response, abuse prevention, accessibility testing with children and guardians, and legal review under applicable Ugandan requirements.
